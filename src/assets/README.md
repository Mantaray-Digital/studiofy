# Assets Folder

Place your authentication page assets here:

1. **auth-bg.png** - Background image for authentication pages (should be placed in this directory)
2. **logo.png** - Your logo image (should be placed in this directory)

## How to add assets:

1. Export the background image from Figma
2. Save it as `auth-bg.png` in this `src/assets/` folder
3. Export your logo from Figma
4. Save it as `logo.png` in this `src/assets/` folder

The pages are already configured to use these images.
